Architecture

How the AI Agent
thinks & acts

Not a simple chatbot. A true agentic loop where Ollama autonomously calls tools, processes results, and reasons across multiple steps.

01
NLP Intent Extraction
Ollama parses natural language — Hinglish, English, or mixed — extracting pickup, drop, date, time, and cab preference.
02
Agentic Tool Loop
Agent autonomously decides which tools to call: geocoder, distance matrix, weather API, surge calculator — in the right order.
03
Real Data Fusion
Live weather + actual road distances + time-aware peak hour detection combine for accurate pricing.
04
Structured Response
Final answer with fare comparison, best pick recommendation, time projections, and animated route map.
